# 校园取件聚合 MVP

这不是一个试图登录淘宝、京东、拼多多账号的爬虫项目。它采用更稳定的三端结构：

1. Android 采集端读取用户明确授权的快递短信和通知。
2. 本地规则从文本中提取取件码、驿站、快递公司和订单号。
3. 脱敏后的包裹摘要同步到自建服务端。
4. 微信小程序展示待取列表、驿站分组和历史记录。

没有短信或通知的包裹可以在 Android 端手动粘贴文本，也可以后续接入截屏 OCR。

## 目录

- `server/`：零依赖 Node.js 同步服务与解析器。
- `miniprogram/`：可直接导入微信开发者工具的原生小程序。
- `android/`：Android 短信和通知采集端源码。
- `preview/`：浏览器端界面预览，用于验证同步服务。

## 本地启动

```bash
./scripts/test.sh
./scripts/serve.sh
```

如果系统已有 Node.js：

```bash
cd server
npm test
npm start
```

服务默认监听 `http://127.0.0.1:8787`。

## 首次配对

1. 小程序打开配对页，生成 6 位配对码。
2. Android 采集端填写服务地址和配对码。
3. Android 端领取设备令牌后，采集结果会同步到小程序。

当前服务是无依赖的 MVP，数据保存在 `server/data/state.json`。正式部署前必须增加 HTTPS、数据库、限流、审计和端到端加密。

## 使用小程序

1. 打开微信开发者工具，导入 `miniprogram/`。
2. 本地调试时可暂时关闭合法域名校验。
3. 如果使用真机调试，把 `miniprogram/config.js` 改为电脑的局域网地址。
4. 正式发布前，将同步服务部署到已备案的 HTTPS 域名，并在微信公众平台配置 request 合法域名。

## 编译 Android

1. 用 Android Studio 打开 `android/`。
2. 安装 Android SDK 35。
3. 连接 Android 手机并安装应用。
4. 在小程序生成配对码，再回到采集端填写服务地址和配对码。

## 重要限制

- 微信小程序不能直接读取短信、通知或其他 App 的数据，必须配合 Android 采集端。
- 取件码通常由快递柜或驿站系统生成，不能从订单号推导。
- 本项目不抓取电商账号，不保存淘宝、京东或拼多多 Cookie。
- 通知监听和短信权限必须在用户主动授权后使用，并应在隐私政策中明确说明。
- 当前 Android 工程只会在本机提取快递相关消息，并对已提取字段做同步，不上传完整短信库。
