# 微信小程序

这是原生微信小程序工程，不需要 npm 安装步骤。

## 调试

1. 启动同步服务。
2. 用微信开发者工具导入当前目录。
3. 开发阶段关闭“不校验合法域名”限制。
4. 打开配对页生成 6 位配对码。

电脑模拟器可以把服务地址保留为 `http://127.0.0.1:8787`。真机需要填写电脑的局域网地址，例如 `http://192.168.1.10:8787`。

正式发布必须使用 HTTPS，并在微信公众平台配置 request 合法域名。当前 `project.config.json` 使用 `touristappid`，发布前需要替换成真实小程序 AppID。
