# Android 采集端

采集端读取用户授权的短信和通知，在本地提取取件码、驿站、快递公司、订单号和运单号。它不登录电商账号，不读取订单页面。

## 构建

要求：

- JDK 17
- Android SDK 35
- Gradle 8.13

```bash
cd android
./gradlew assembleDebug
```

产物位置：

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 使用

1. 安装 APK。
2. 小程序生成 6 位配对码。
3. Android 端填写服务地址和配对码。
4. 授权短信权限。
5. 在系统设置中开启“校园取件通知识别”的通知使用权。
6. 点击“导入最近 7 天快递短信”，之后新短信和通知会自动处理。
7. 没有短信或通知时，复制取件消息后点击“粘贴取件消息并识别”。

## 当前边界

- 不包含截屏 OCR，短信和通知拿不到时可以后续接入。
- 当前只允许读取常见电商和快递 App 的通知包名。
- 本地队列使用 SharedPreferences，适合 MVP；数据量大后应换成 Room。
- 仅在用户主动授权后工作，必须在上架前提供完整隐私政策和权限说明。
